### 👨‍💻 About Me

Hi, I'm **Rajal** — a software engineer and systems builder focused on **scalable distributed architectures**, **cloud networking**, **low-level systems**, and **autonomous agentic AI**.

- ☁️ **Cloud & Distributed Networking**: Architecting isolated, air-gapped VPC enclaves, serverless concurrency controllers, and high-throughput pipelines.
- 🤖 **Autonomous AI & Agentic SDLC**: Building governed agent architectures (Sentinel Spec), local RAG triage agents, and multi-actor LangGraph workflows.
- ⚙️ **Systems & Core Computing**: Engineering POSIX-compliant shells in C, single-binary log search engines in Go, and automata simulators.
- 🛡️ **Cybersecurity & Machine Learning**: Developing ML-driven intrusion detection systems (NIDS) and AI media copyright defense platforms.
